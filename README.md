# Tachyon — трекер финансов

Многопользовательское приложение для учёта доходов и расходов с лимитами бюджета,
повторяющимися операциями и прогнозом трат через REST API.

![logo](assets/logo.png)

## Стек

Python, Flask/FastAPI, SQLAlchemy + SQLite, pandas для отчётов,
APScheduler для повторяющихся операций, pytest для тестов.


## Локальный запуск

Требуется Python 3.11 или новее.

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python -m uvicorn app.main:app --reload
```

После запуска доступны:

- health-check: <http://127.0.0.1:8000/health>;
- Swagger: <http://127.0.0.1:8000/docs>;
- ReDoc: <http://127.0.0.1:8000/redoc>.

### Проверка

```powershell
python -m pytest
python -m ruff check .
```

Файл `.env` содержит локальные настройки и секреты, поэтому не добавляется в Git.
Шаблон допустимых переменных находится в `.env.example`.
